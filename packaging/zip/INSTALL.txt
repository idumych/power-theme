Reactionary for Renku OS and Haiku
==================================

A Windows ME style look after the Reactionary ME theme for KDE Plasma
(Die4Ever, store.kde.org/p/2331482): a window decorator, a control look,
desktop and system colours, fonts, and the ClassicOS 2000 icons. With it
comes Themes, which switches between themes and icon themes, and back.

This is an independent port, not made by or affiliated with the authors
of Reactionary ME or ClassicOS 2000.

Install
-------
Unpack the zip, open a Terminal in the reactionary folder and run:

    sh install.sh

If a compiler is installed, this builds Reactionary against your own
system first, which is the safest way: the decorator runs inside
app_server and uses its private classes. Without one it uses the prebuilt
files, which were made on the Renku build named in prebuilt/BUILT_FOR. To
get the compiler:

    pkgman install gcc make haiku_devel
    sh install.sh --build

Everything goes into ~/config/non-packaged; no package is installed.
Applications that are already running pick up the new controls and fonts
when restarted; logging out and in (or rebooting) gets everything.

Tested on Renku x86_64 (hrev60072+339).

Themes
------
Themes is in Deskbar's Applications menu. It lists the installed themes
and icon themes, applies them (all of a theme, or some of its parts) and
puts your previous look back. From a Terminal:

    Themes --list              installed themes and icon themes
    Themes --apply="Reactionary ME"
    Themes --icons=ClassicOS2000    only the icons ("haiku" for Haiku's)
    Themes --revert            your previous look and icons
    Themes --help

The "Haiku" theme switches back to stock Haiku: its window borders,
controls, colors, fonts, wallpaper and icons. The "Gonx" theme comes with
Gonx's controls; its window borders are built by Themes (below).
The "Renku" theme puts Smoke window borders and flat controls in the
Renku OS website's colours, night blue with fire orange.
DarkFlat, LightFlat, MoonFlat and OrangeFlat come from haiku_darkstyle by
unarix (github.com/unarix/haiku_darkstyle), with Haiku's Flat window
decorator and control look, which install.sh installs if your system
doesn't have them. "Themes --revert" goes back to your own
look from before the first theme, customizations included.

Window borders and controls build on private parts of the system, so
they must be built for the exact system they run on. In Themes,
"Build add-ons..." compiles them (Reactionary, Smoke, Gonx, Flat) for the
running system, fetching its headers if they differ from the bundled
ones, and offers to install the compiler if it is missing. From a
Terminal: Themes --build-decorators. Do this again after every system
update.

Themes made for Theme Manager are listed too: put them in
~/config/settings/UIThemes, as Theme Manager expects. Those that ask for
ZETA's Smoke decorator get Smoke, a window decorator and control look in
its style that install.sh installs (redrawn from screenshots; nothing from
ZETA is included).

More themes go in ~/config/non-packaged/data/themes, icon themes
(freedesktop icon themes, PNG or SVG) in ~/config/non-packaged/data/icons.

Undo
----
    Themes --revert        your previous decorator, controls, colours,
                           desktop colour, fonts and icons
    sh uninstall.sh        reverts and removes Reactionary

If the desktop ever fails to start (for example after a system update):
hold Space while booting, open "Select safe mode options" and choose
"Disable user add-ons"; once on the desktop, run sh uninstall.sh, or
sh install.sh --build to rebuild Reactionary for the new system.
